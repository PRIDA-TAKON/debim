# Contemporary Thai House 5 (บ้านครอบครัวไทยร่วมสมัย ๕)

โครงการต้นแบบบ้านพักอาศัย ค.ส.ล. 2 ชั้น (4 ห้องนอน 3 ห้องน้ำ) จาก **กรมโยธาธิการและผังเมือง กระทรวงมหาดไทย** นำมาแปลงเป็นแบบจำลองเชิงประกาศ (Declarative BIM / Building-as-Code) ด้วย [debim](https://github.com/PRIDA-TAKON/debim)

---

## 📐 Project Information

- **ชื่อโครงการ:** แบบบ้านครอบครัวไทยร่วมสมัย แบบที่ ๕ (แบบบ้านสานฝัน ของขวัญปีใหม่ คนไทยมีความสุข)
- **หน่วยงานผู้ออกแบบ:** สำนักสถาปัตยกรรม & สำนักวิศวกรรมโครงสร้างและงานระบบ กรมโยธาธิการและผังเมือง
- **แบบเลขที่:** S-58136, AR-58005, SN-58082, EE-58081
- **ขนาดที่ดินขั้นต่ำ:** กว้าง 14.10 ม. ยาว 19.40 ม. (ขนาดตัวบ้าน 9.00 x 13.40 ม.)
- **พื้นที่ใช้สอย:** รวมประมาณ 200+ ตร.ม.

---

## 🧱 Structural Specification

- **ระบบโครงสร้าง:** คอนกรีตเสริมเหล็ก (ค.ส.ล.) หล่อในที่ ผสมพื้นสำเร็จรูปท้องเรียบ
- **กำลังคอนกรีต:** $f'_c \ge 210\ \text{ksc}$ (ทรงกระบอก 28 วัน)
- **เหล็กเสริม:**
  - เหล็กเส้นกลม ผิวเรียบ: **SR-24** ($\phi 6, \phi 9\ \text{mm}$)
  - เหล็กข้ออ้อย: **SD-40** ($\text{DB}12, \text{DB}16, \text{DB}20\ \text{mm}$)
- **ความสูงแต่ละชั้น:**
  - ระดับตอม่อ/ฐานราก: -1.50 ม.
  - ระดับพื้นชั้น 1: +0.00 ม. (ระดับพื้นแล้วเสร็จ +0.60 ม.)
  - ระดับพื้นชั้น 2: +3.75 ม.
  - ระดับคานอะเส/หลังคา: +6.65 ม.

## 🚀 Usage

### 1. ตรวจสอบความถูกต้องของโมเดล
```bash
bim validate -m examples/contemporary_thai_house/project.yaml
```

### 2. ถอดปริมาณงานวัสดุ (QTO)
```bash
bim qto -m examples/contemporary_thai_house/project.yaml
```

### 3. ประเมินราคาค่าก่อสร้าง (Cost Estimation)
```bash
bim cost -m examples/contemporary_thai_house/project.yaml -p examples/contemporary_thai_house/prices.json
```

### 4. แปลงเป็นไฟล์ IFC4 มาตรฐานสากล
```bash
bim compile -m examples/contemporary_thai_house/project.yaml -o examples/contemporary_thai_house/model.ifc
```

### 5. เปิดดูโมเดล 3D ในเว็บเบราว์เซอร์
เปิดไฟล์ `examples/contemporary_thai_house/viewer.html` หรือรัน:
```bash
bim view -m examples/contemporary_thai_house/project.yaml
```
