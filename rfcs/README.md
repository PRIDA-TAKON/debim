# debim RFCs (Request for Comments)

ยินดีต้อนรับสู่กระบวนการ **debim RFC** ซึ่งเป็นช่องทางหลักในการเสนอ ถกเถียง และอนุมัติการเปลี่ยนแปลงในระดับสเปกของภาษา `debim (Declarative BIM)`

---

## 📌 ขั้นตอนการเสนอ RFC

1. **คัดลอก Template:** ทำสำเนาไฟล์ [`0000-template.md`](file:///C:/Users/takon/OneDrive/Desktop/da/43-debim/rfcs/0000-template.md)
2. **ตั้งชื่อไฟล์:** ตั้งชื่อไฟล์ตามลำดับ เช่น `0002-my-feature-name.md`
3. **เปิด Pull Request:** ยื่น PR เข้ามาที่โฟลเดอร์ `rfcs/` เพื่อเปิดรับฟังความเห็นจากชุมชน
4. **กระบวนการพิจารณา:** คณะทำงาน (Working Group) และชุมชนจะร่วมแสดงความคิดเห็นและทดสอบ
